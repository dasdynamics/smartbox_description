## smartbox_description

Репозиторий содержит ROS 2-пакет с описанием робота **SmartBox**.

Робот представляет собой квадратный корпус с двумя ведущими колёсами и двумя поддерживающими колёсиками. В данной модели поддерживающие колёса реализованы как фиксированные сферы.

***

## Требования и установка

Для работы пакета требуется установленный ROS 2. В данном случае используется дистрибутив **ROS 2 Lyrical**.

Также необходимо установить пакет `xacro`:

```bash
sudo apt install ros-lyrical-xacro
```

Для корректного отображения всех узлов робота совместно с основным описанием запускается **Joint State Publisher**. Установить его можно командой:

```bash
sudo apt install ros-lyrical-joint-state-publisher-gui
```

***

## Быстрый запуск

После сборки пакета для быстрого запуска можно использовать файл запуска:

```bash
ros2 launch smartbox_description description.launch.py
```

***

## Настройка параметров робота

Основные свойства робота можно легко изменить, отредактировав файл `properties.xacro`.

> **Примечание:** При проектировании робота был применён модульный подход. Каждый значимый элемент робота — это отдельный модуль, внутри которого размещён сам элемент и компоненты, обеспечивающие его работоспособность.

### Доступные для изменения свойства:

**Корпус шасси:**
- `chassis_box_mass` — масса корпуса шасси (используется для расчёта инерции)
- `chassis_box_length` — длина корпуса шасси
- `chassis_box_width` — ширина корпуса шасси
- `chassis_box_height` — высота корпуса шасси

**Ведущие колёса:**
- `drive_wheel_mass` — масса ведущего колеса (используется для расчёта инерции)
- `drive_wheel_height` — высота ведущего колеса (применяется к обоим колёсам)
- `drive_wheel_radius` — радиус ведущего колеса (применяется к обоим колёсам)
- `drive_wheel_separation` — расстояние по оси **Y** между ведущими колёсами

**Поддерживающие колёса:**
- `support_wheel_mass` — масса поддерживающего колеса (используется для расчёта инерции)
- `support_wheel_radius` — радиус поддерживающего колеса (применяется к обоим колёсам)
- `support_wheel_separation` — расстояние по оси **X** между поддерживающими колёсами

**Корпус лидара:**
- `lidar_box_mass` — масса корпуса лидара (используется для расчёта инерции)
- `lidar_box_length` — длина корпуса лидара
- `lidar_box_width` — ширина корпуса лидара
- `lidar_box_height` — высота корпуса лидара

**Лидар:**
- `lidar_mass` — масса лидара (используется для расчёта инерции)
- `lidar_height` — высота лидара
- `lidar_radius` — радиус лидара

> Если необходимое свойство не найдено среди указанных выше, внесите изменения непосредственно в основные файлы описания в директории `urdf`.

***

## Структура файлов описания

| Файл | Описание |
|------|----------|
| `bringup.urdf.xacro` | Основной файл. На него ссылается launch-файл при запуске. Содержит последовательность подключения остальных файлов для корректной сборки описания робота. |
| `properties.xacro` | Файл с основными свойствами робота. |
| `inertia_macros.xacro` | Содержит макросы для расчёта инерции, используемой в симуляции. |
| `chassis_box.xacro` | Описание корпуса шасси. |
| `wheels.xacro` | Описание колёс шасси. |
| `lidar_box.xacro` | Описание корпуса лидара и самого лидара. |
| `gazebo_plugins.xacro` | Плагины для симуляции робота в среде Gazebo. |
